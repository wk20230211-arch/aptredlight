APTREDLIGHT · WordPress CMS 一次性数据库绑定

已完成：工作台站主管理员身份绑定、Hostinger SSH 公钥登录、服务器身份核对。
尚缺：新建 WordPress 所需的 MySQL 数据库连接。Hostinger 当前 MCP 对该托管账号返回 404，无法代建数据库；这不是再次索取发布授权。

推荐使用私有工作台配置页 https://aptredlight-growth-desk.wk20230211.chatgpt.site/woocommerce/cms-setup.html 完成填写和复制，避免手动拼 JSON。

1. 在 https://hpanel.hostinger.com/websites 选择 aptredlight.com。
2. 打开“数据库 → 管理”，创建一个专用空 MySQL 数据库，创建或关联它的数据库用户，设置至少 12 位的新密码。
   - 保存完整数据库名与完整数据库用户名，必须以 u469397229_ 开头。
   - 不要选择已有业务数据库；程序会拒绝向非空数据库安装。
   - 此处需要数据库密码，不是 SSH、GitHub 或 Hostinger 登录密码。
3. 在上述私有配置页 填写数据库名、用户名、数据库密码、主机（通常 localhost）和管理通知邮箱，点“复制 Secret 内容”。本页不发送请求、不记录表单、不使用本地存储。
4. 打开 https://github.com/wk20230211-arch/aptredlight/settings/secrets/actions/new
   Name：APTREDLIGHT_CMS_DATABASE
   Secret：在大框按 Ctrl+V，粘贴上一步复制的内容。
   然后点击 Add secret。
   如果已有同名 Secret，点铅笔图标更新。
5. 回复“数据库 Secret 已保存”。我们重跑已准备的安装 job，无需重新运行 Windows PowerShell、提供管理员 ID 或重复登录 SSH。

手动配置格式（只粘贴到 GitHub Secret，不发送聊天）：
{"name":"u469397229_你的数据库名","user":"u469397229_你的用户名","password":"你的数据库密码","host":"localhost","admin_email":"你的管理邮箱"}
如密码含引号或反斜杠，必须按 JSON 转义；建议使用随附页面自动生成。
